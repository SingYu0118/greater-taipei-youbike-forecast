# Data Sources and Provenance

Every external input is public and requires no credential in the current implementation. Raw responses are retained with fetch time and SHA-256 checksum so a processed row can be audited back to its source object.

| Input | Purpose | Official source | Collection policy |
|---|---|---|---|
| Taipei YouBike live availability | Station state and metadata | [Taipei live JSON](https://tcgbusfs.blob.core.windows.net/dotapp/youbike/v2/youbike_immediate.json) | Every five minutes |
| New Taipei YouBike live availability | Station state, metadata, mechanical and electric counts | [New Taipei dataset](https://data.ntpc.gov.tw/datasets/010e5b15-3823-4b20-b401-b1cf000550c5) | Every five minutes; fetch all pages |
| Open-Meteo forecast | Issue-time weather known at prediction time | [Forecast API](https://open-meteo.com/en/docs) | Once per hour for three representative grids |
| Taipei Metro station coordinates | Nearest-MRT distance feature | [Taipei City Data Platform dataset](https://data.taipei/dataset/detail?id=1eefa68d-7c8d-491b-8e75-66a161947426) | Versioned reference snapshot |
| Taiwan public holidays | Holiday calendar feature | Python `holidays` package, Taiwan calendar | Deterministically generated by date |

## Known provenance limits

- The live feeds expose current state, not historical state. History begins only when this collector starts.
- Official source update timestamps and collector fetch timestamps are preserved separately.
- The three weather grids approximate spatial variation; they are not station-level weather sensors.
- The current MRT reference covers the official Taipei Metro dataset. Future work should reconcile additional New Taipei light-rail systems in a separately versioned source.
- Public events are intentionally excluded because reliable historical publication time is not consistently available; adding them without that timestamp could introduce future leakage.
